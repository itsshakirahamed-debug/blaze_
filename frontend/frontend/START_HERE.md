## 🎯 Quick Start Guide

### Step 1: Install
```bash
cd frontend
npm install
```

### Step 2: Run
```bash
npm run dev
```

### Step 3: Open Browser
Open **http://localhost:5173**

### Step 4: Test the App
1. Click "Get Started" on home page
2. Drag a PDF/DOCX file to upload
3. Click "Analyze Contract"
4. Wait for results
5. View charts and analysis
6. Download report
7. Try "Analyze Another"
