# 🎯 JUST RUN THIS! (3 Commands)

## The Absolute Quickest Way to Get Started

### Command 1: Go to frontend folder
```bash
cd frontend
```

### Command 2: Install packages (first time only)
```bash
npm install
```

### Command 3: Start the development server
```bash
npm run dev
```

### That's it! 🎉

**Your browser will show:**
```
  VITE v8.1.5  ready in 234 ms

  ➜  Local:   http://localhost:5173/
```

Click that link or open **http://localhost:5173** in your browser!

---

## What You'll See

1. **Beautiful landing page** with features
2. **Upload button** - try uploading a PDF or DOCX
3. **Results dashboard** with charts and analysis
4. **Mobile menu** - works on phones too!

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+C` | Stop the dev server |
| `F12` | Open browser developer tools |
| `Ctrl+Shift+M` | Toggle mobile view |
| `Ctrl+R` | Refresh browser |

## If Something Goes Wrong

**Issue: Port 5173 is busy?**
```bash
npm run dev -- --port 3000
```

**Issue: Can't find npm?**
```bash
node --version    # Check Node.js is installed
npm --version     # Check npm is installed
```

**Issue: Still have problems?**
See `HOW_TO_RUN.md` → Troubleshooting section
